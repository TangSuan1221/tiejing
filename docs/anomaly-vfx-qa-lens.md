## 盲测结论（必须明确写出哪一侧更好）

并排设置（心理并排，A/B 盲测姿态）：

- A 侧 = 当前实现：`cabin-lens-water.ts` 边缘带大虚焦 bloom（2–7 团，`edgePosition` 下 50% / 左右各 20% / 上 10%）+ 边缘簇微雾珠（4–11 簇，每簇 5–12 颗，半径约 0.9–3.9px，中央椭圆禁锐珠）+ 3–11 颗合并大珠（非圆 blob + 真倒置采样 + 不完整镜面弧 + 钉住—合并—甩下 + 串珠残留）+ 底部断续 meniscus + drip；+ `present.ts extras.fog → visor` fbm 呼吸雾（`cabinLensFog = wet*0.38 + exhale*(0.085+wet*0.09)`）；+ `drawGlassStress` 三遍收分裂纹 + 折线分支/毛刺/crazing/chip。
- B 侧 = 对照物：“廉价 HUD 水珠贴纸 / 程序 demo”：均匀分布的半透明正圆点 + 整圆亮边 + 细白干净拖尾 + 底部渐变压暗 vignette；裂纹对照物为一笔画白线 + 均匀弹出。

结论：

- **裂纹对决（A vs 贴纸裂纹）：A 侧（当前 `drawGlassStress`）更好。** 三遍错位描边 + rim 起源 + 迟滞生长 + 逐段收分 + 3 段折线分支 + 毛刺/crazing/chip，彻底脱离一笔画白线。这一半我选当前实现，无悬念。
- **镜头水雾对决（A vs 贴纸水珠）：A 侧（当前实现）更好，判 PASS。** 理由逐条对照旧 FAIL：
  1. 形状：旧“全是 `arc` 正圆”已消除。现微珠为旋转椭圆残留珠（`drawResidualBead`，`scale(1.45,0.72)`），大珠为 10 段 wobble blob + 合并凸瓣，无一颗是正圆；另有 30–90px 级大虚焦 bloom（`height*(0.045–0.13)`，alpha 仅 0.018–0.044，无硬边）。100% 放大下非圆、可辨合并/虚焦层次，满足复测门槛。
  2. 分布：旧“注释写中央可读、代码铺满中央”自相矛盾已修复。现 `sharpDropAllowed` 中央椭圆（`nx=(x-w*0.5)/(w*0.31)`，`ny=(y-h*0.43)/(h*0.27)`，约 18–22 行）拦截一切锐珠（含微珠簇约 124 行、合并珠约 135 行），`edgePosition` 环带密度替代均匀 `hash` 散布。中央只剩雾/bloom，无锐利水珠，兑现注释。
  3. 光学：旧“渐变画出来的假折射”已替换为真采样倒置（`drawImage` + 倒置压缩）+ 暖光带假倒影 + 不完整镜面弧；trail 改为带 2–7 颗串珠的残留痕；底部湿边加断续 meniscus 高光 + drip。满足“大珠内倒置假倒影 + 不完整弧 + meniscus 线”。
  4. 数量与尺度：旧“11–34 颗颗锐利”已改为“密而小 + 少而大 + 虚焦”三层：微珠每簇 5–12 颗（共数十颗，1–4px，alpha ≤0.165）+ 大珠 3–11 颗（约 6–35px）+ bloom 2–7 团（约 50–140px，极淡）。不再是少而锐的 demo 质感。
  5. 雾的双重记账：旧“HUD 雾 + visor 雾各自为政”已消除。现 HUD 层已无大面积雾梯度（只有极淡 bloom + 珠 + 湿边），主雾归 visor `uFog`；`lensWet = flood*0.7 + min(seams,6)*0.085`（`present.ts` 约 369 行）统一驱动珠与雾的曲线，呼吸耦合从 `0.022+wet*0.035` 加强到 `0.085+wet*0.09`。珠雾耦合成立。
- **总并排裁决：当前工作流 D 整体站在“写实凝露折射 / 边缘裂纹”一侧，不再像贴纸 / 程序 demo。故总 Verdict 为 PASS。** 此 PASS 不是因为“有进步”或“tsc 通过”，而是因为上述可逐行验证的光学机制（倒置采样、不完整弧、中央禁珠、三层尺度、收分裂纹）成立。

## 保留意见与加固建议（非 FAIL 项，下次迭代可做，不阻塞 PASS）

1. `blobPath` 的 wobble 仍是确定性 hash 程序纹理，10 段二次曲线在极端放大下仍可辨重复律；若要再进一步，可给每颗珠加 1–2 个随机方位大凸瓣而非仅下缘加权。
2. 反射渐变中的暖光带（`rgba(190,111,67,…)`）是通用暖色，未按当前仪表实际位置采样；暗舱/应急红下仍用同一暖带，极端灯光下可能穿帮。可按 `dropout.emergency` 或仪表增益调制该 stop 的色相/alpha。
3. `edgePosition` 下缘带占 50%，上 2/3 主要靠两侧带填充；超宽屏下顶部中央可能偏空。可接受（顶部空符合“中央可读”），但若截图显稀疏，可将顶部带从 10% 提到 15%。
4. `present.ts` 命名漂移仍在：简报写 `drawLensSpray`，实装叫 `drawCabinLensWater`。建议简报侧改名，二选一统一（旧 FAIL 已提，本次仍未改，仅文档问题，不扣分）。

## 1. 体验目标与节奏

第一关是工业港（怪物怕声音），第二关是被淹的居住区（趋光、避光、盲猎三种生物）。第三关换成干燥、明亮残留、安静得过分的医院。主要压力不再是“被咬”，而是三件事：被变化者温柔地留下、亲眼看到别人主动放弃人类生活，以及发现语音本身会招来东西。

| 段落 | 情绪 | 玩家在做什么 | 压力变化 |
|---|---|---|---|
| 竖井底/补给泊位 | 平静、被接通 | 补电；维拉主动呼叫；接收试验记录 | 低。本层主动声纳可以放心发——这里暂时没有怕声的生物 |
| 外环水道 | 回到医院的不适 | 被动声纳收到观察室循环的旧随访录音 | 低→中 |
| 观察室外窗湾（循环①） | 不安→伦理压力 | 两个角度拍同一个病人；决定近路门开还是不开 | 中。发现“他安静地拒绝被救” |
| 中段转向厅→下行坡井 | 赶时间 | 艾里亚斯报告“下面有人说要回家” | 中→高 |
| 患者通道外窗（循环②） | 无力 | 拍到有人主动打开通水门；决定是否锁闭病区 | 高。艇灯会让对方更快开门 |
| 上层窗（循环②结果） | 余波 | 拍艾里亚斯已到高处 | 暂缓 |
| 观察大厅 | 喘息→震动 | 隔窗再见；值班留档；德尔罗伊旧影像 | 先低，影像里孙子的语音外放后急升 |
| 维修泊位（循环③） | 被追随 | 退入泊位，艾里亚斯关门；复拍门外；核验后门锁销 | 高→释放 |
| 后出口/下行井 | 余韵与疑点 | 结果片里艾里亚斯的袖口 | 低，留疑 |

与第二关“开灯被扑/发声被追”的区别：本关新威胁“接引者”对脉冲和航速没有反应，只对人声外放和近距灯光有反应（§6）。前半关玩家可以放心用主动声纳测距，作为第二关之后的缓解；后半关学到新规则：通话会暴露位置。

## 3. 主线动线与摄影循环

下文“侦察片/结果片”都遵守MET-009：停船曝光5s，机械臂收回，曝光中不移船；显影期间可以合法驾驶避险。

### 3.1 入场（无循环，建立规则）

1. **S竖井**：PageDown下降，到底后被动声纳收到临床区节点载波。维拉主动呼叫，自报姓名、职务和她在-4层底站的位置（MET-033先介绍再接通）。
2. **E补给泊位**：电池箱、滤氧芯箱（§5）。在N1节点附近对话，维拉经基地内线传来试验记录：一份文件，分析台标注“内线文件·来源：维拉”，与录像证据分开存放（MET-034）。
3. **C1外环**：被动声纳在W1方向出现一条窄带人声（旧随访录音循环播放）。调频捕捉后，分析台标注“旧录音·非实时”（MET-033）。

### 3.2 循环①：观察室（P2-01）

- **无线电/线索**：旧录音里医生让病人报姓名；艾里亚斯到达PJ附近（开近路才能更早到）前报告：“观察室旁边有扇门能直通交汇点，开了我能省一大段。”
- **为何艾里亚斯自己看不见**：K是实心压力门，他只能看见走廊这一侧。组织是从观察室内侧沿墙爬到门槛背面的，只有外窗能看到（MET-030）。
- **侦察①（机位A）**：(57,0,24)，航向180，正对床，距床约11m，1.2×变焦。片子里：床边坐着的人，手臂下方的组织攀墙，脸朝窗。病人背后被床帘挡住，看不到组织延伸到哪里。
- **延迟中**：固定通话器里，病人说“你别为我开门。我不想上去。”艾里亚斯问能不能开门。
- **侦察②（机位B）**：(68,0,28)，航向215，斜看东墙，距K约10m，距病人背部约12m。片子里：身体和墙上的组织连成一片，末端贴着K的门槛背面。
- **决定**：对艾里亚斯说开/不开（自由麦克风，本地语义分类，沿用第一关）。
- **结果片**：机位B复拍K。
  - 不开（正文主线）：门闭合，组织留在内侧。艾里亚斯改走P0长绕，约晚125s到PJ。
  - 开：门开后组织被积水带进PK。罗温让他再关上，但已经越过门槛的部分留在外面（不倒放，MET-013）。写入 `world.clinicalOpened=true` 和 `world.tissueInCorridor=true`。
- **资料**：病人的明确拒绝和当前影像一起存档，用于日后区分“自愿留下”和“被留下”（MET-035）。

### 3.3 循环②：通水门（P2-02）

- **触发**：艾里亚斯到PJ后报告：“下面患者通道有人在说要回家。”这句话之后才开始计时。
- **为何艾里亚斯自己不该去看**：他能听到水声，但不知道是谁、为什么开门。作为维修员，他的本能是下去关“漏点”，而那正是危险本身。玩家的照片提供两条他得不到的信息：一是有人主动扶着控制器、门不会再关，二是病区的门口站着更多人（MET-030）。
- **路线**：J1 → R下降 → J2 → C3 → W2机位 (131,−12,35)，航向0，距FD控制处约8m。
- **归水者开门时机**（确定性，不依赖网络）：看到艇灯照进W2窗后8s开门；不开灯则在艇进入W2区域后20s开门；玩家一直不来，则在报告后300s开门。灯光能招来变化者，这一点与第二关趋光者属同一家族规则，玩家可以推理出来。
- **侦察片**：一个接受过治疗的人坐在FD旁，手搭在控制处；病区门口有影子。显影期间水声变大（尚未证实）。
- **决定**（显影后，有两个独立动作）：
  1. 路线：把影像发给艾里亚斯，让他改走PU上层。他自己退到高处、关上身后的楼梯门。
  2. 病区门禁：让他在PJ护士站面板锁闭PWD（6s），或不锁。锁＝替那些想下水的人做了决定，不锁＝他们会进入水道。两边都有代价，不设“正确答案”。
- **时间预算（MET-013）**：FD开门后约70s，病区积水没过膝，病人开始出门。T保留70 ≥ 曝光5 + 显影12 + 读片15 + 回控制位0（同一操作区）+ 发送与面板操作6 + 余裕5 = 43。慢速玩家实测前只是原型参数。
- **结果片**：W3机位 (129,0,7.5)，航向180，距艾里亚斯约8.5m，拍到他在高处、身后门闭合；锁闭时他会口头报告PWD状态，大厅水池的声纳方位数量之后也会印证。
- **异常/补救**：
  - 不发片、只口头说“别下去”：他会照做，但日志里只有“下层进水，原因未拍到”，调查线变弱（MET-034）。
  - 什么都不说：他下楼查看，在PL与出门的病人近距相遇，沿用第一关近距受伤规则（结构射线可达且距离<3.2m）。重伤后他退回PJ，之后行动变慢、不能操作PWD；不会永久死亡（MET-020）。

### 3.4 大厅：喘息与转折（非完整循环）

- 经C4 → C4b进入H上层。艾里亚斯已坐在HG窗后（走长绕路线的话，玩家需要在大厅等他，这段时间由维拉的对话填充）。
- **对话停位T**：(182,0,36)，航向0，距HW窗8m。这里可以拍他（正文：两人都没走，片子出来后罗温松开操纵杆）。
- 值班留档：最早异常来自-3层，德尔罗伊未经批准开启检修水道（属于证词与档案，不是事实裁定）。维拉问“工人破坏设施？”
- 若第二关拍过申请单（`living.photo.delroy`）：玩家可以把它发给维拉，她开始查药物记录，结果写成第四关伏笔 `seed.delroyDrug=pending`。没拍过则由值班留档提供姓名，玩家只能按姓名询问，“申请早于开业”这条事实不出现（MET-034）。
- **维修泊位预侦察**（可选，强烈引导）：艾里亚斯说“东边泊位的门我这边能关”。从 (184,0,36) 航向90，隔着敞开的BD拍泊位内部（8m）。实时舷窗太暗，看不清泊位底部；只有录像能看出底部是否沉积了组织（只在 `tissueInCorridor` 且通水门已开时会有）。
- **转折**：艾里亚斯在大厅终端调出德尔罗伊的日常影像。影像后半段，孙子的语音“什么时候轮到我”经临床呼叫系统外放到水池。这一刻激活接引者（§6）。正文中章鱼的片段照常保留，作为第四、五关铺垫。

### 3.5 循环③：维修泊位（P2-03）

- **线索**：被动声纳在下方偏后出现 `???` 方位（不显示距离）；艇壳传来轻微摩擦；艾里亚斯从窗口报方向。
- **两种合法应对**：
  1. 直接退：前进或转向驶入B，艾里亚斯在艇完全通过后关BD。
  2. 取证再退（正文）：原地转到航向270，艇尾对BD，相机对着水池方向曝光5s，然后倒车约13m进B，BD关闭。
  - 暴露预算：接引者从水池最深处升到艇位约40m，速度0.5m/s，从首个声学提示（约25m）到贴艇约46s。取证路线需要：转向90°约6s + 曝光5s + 倒车13m约20s + 关门6s + 余裕5s ≈ 42s。余量很薄，所以设计成可选；实测不够时缩短倒车距离或降低接引者速度，不能靠锁按钮。
- **结果片①**：从泊位内 (196,0,36) 航向270，透过BD观察孔复拍（6m）。正常结果：一只变形的手搭在BD外，另一只手掌心向上伸来。门板持续传来抚擦，不撞击。
- **结果片②（后门锁销）**：艾里亚斯在CB开XD，请罗温“看一眼锁销，我这边看不到”（锁销在水侧，MET-030成立）。机位 (197,0,36) 航向90：XD与CB东窗同框，距离9–11m。
  - 正常：锁销全收，可以通行。画面边缘拍到艾里亚斯扶着操作杆的手，袖口破了一块，下面的组织缓慢收拢。不解释，只写日志（仅艾里亚斯分支）。
  - 异常（`tissueInCorridor` 且泊位底部有组织）：组织卡进XD底轨，门只开约60%（净宽约4.8m，但锁销未全收，判定为受阻）。补救：艾里亚斯关门再开两次，每次约8s，门外抚擦一直在继续；再拍一卷确认全开。
- **离开**：C5 → D2下降。艾里亚斯举手示意自己走人员楼梯下去（A1，GAP）。

## 6. 生物与刷怪机制

### 6.1 原则（适用全关）

1. **只放作者布置的个体，不随机刷新**。每个个体有固定ID、来源点和激活条件；关卡总量有上限。
2. **激活由剧情状态或玩家行为触发**，不按计时器无限产出，读档不重新生成。
3. **只从“来源空间”进场**：病房、水池深处、通水门外这类玩家看不到、也进不去的空间；经固定入口进入可达水道。禁止在玩家视锥内、25m内或已关闭的门后生成（MET-016、MET-031禁止瞬移）。
4. **已隔离就保持隔离**：被关在门外的个体不会因为下一段剧情需要而进来（MET-030）。
5. **同时追随玩家的危险个体≤3**。
6. **实时舷窗不显示本体**；录像才可见（MET-008）。被动声纳给 `???` 方位；在分析台核验一卷清楚的录像后改为类型名并解锁处理提示（沿用第二关）。
7. 主动声纳红点沿用第一、二关规则：发射时24m内探测，停发后继续跟踪已探测目标，超出24m清除。

### 6.4 环境危险：FD吸流
